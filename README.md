# 웹 카메라 독립 진단 V2

Galaxy A36 5G의 웹 후면 카메라 실행 실패를 분석하기 위한 독립 진단 페이지입니다. 외부 AR 라이브러리를 사용하지 않습니다.

실행: https://imm-content.github.io/camera-diagnostic/

## 테스트
1. 전면 카메라 실행 및 권한 허용
2. 카메라 목록 조회
3. 카메라 종료
4. 목록에서 후면 카메라 선택 후 기본 해상도 조건으로 실행
5. 실패 시 저해상도 조건으로 재시험
6. 다른 후면 카메라가 노출되면 각각 반복

기존 facingMode 호출과 deviceId 직접 지정 호출을 비교합니다. 해상도는 강제 조건이 아닌 선호 조건입니다. 브라우저가 모든 물리 렌즈를 노출하지 않을 수 있습니다. 종료 후 1.5초 대기하며 실제 오류명과 영상 설정을 기록합니다. 실기기 검증 전 진단용 버전입니다.
